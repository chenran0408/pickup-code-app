# 码上闪记 v1.3.1

本版整理了首页和设置，让查看取件信息更直接。

- 首页增加淘宝、菜鸟和拼多多身份码快捷入口，并把记录筛选收纳到一个菜单。
- 悬浮底栏集中显示首页与设置；通知来源、识别规则、地址、统计和回收站按用途归类。
- 调整常用按钮的底色，减少容易被误认为不可用的灰色块。
- 保留离线识别和本机记录，支持大字显示与深浅色主题。

适用于 Android 8.0 及以上的 arm64 手机。请从本页下载 `app-arm64-v8a-release.apk`；下载后可用 `SHA256SUMS.txt` 核对文件。此版本沿用现有正式签名，可覆盖升级并保留已有记录和设置。不要卸载旧版来绕过签名错误，以免丢失本机数据。
