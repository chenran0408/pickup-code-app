# 微信通知识别与界面同步

设置 → 输入方式 → 短信与微信识别 → 微信通知识别。开关默认关闭，与短信通知开关独立；共同使用系统“取件码通知识别”通知访问权限。已有授权会沿用，不改服务组件名。

仅处理 com.tencent.mm 发出的新通知可见正文，本地提取取件码、取餐码并应用类型开关/置信度过滤。排除分组摘要、金融噪声、身份码页面和重复更新。MessagingStyle 只处理最新收到消息，不读历史聊天，不调用在线 AI。其他 App 不纳入本次监听。

真实验证：开启微信消息通知和通知显示详情，离开测试会话，请另一账号发送“【圆通快递】凭7-3-5268到青禾村24排4号取包裹。”。确认微信确实弹出带正文通知，应用待取清单应出现7-3-5268；再发送同文应合并而非新增。关闭微信识别后，发另一个码应不新增，短信监听仍可使用。聊天前台、免打扰或隐藏正文导致无通知/无正文时无法识别。

界面同步检查：

- 规则页删除“识别全靠正则”的表述；对应前缀正则注明八位柜机码，凭码句式注明到/至。
- 用户规则页仅保留可管理的规则；已移除只读上下文与校验说明及格式白名单，页面介绍简化为操作提示。通知分段、逐码字段、期限和安全过滤继续生效。
- 正则快照显示实际生效表达式，特殊模式不显示无效改写。
- 设置到期提醒文案纳入免费保管期限；系统授权服务名同时覆盖短信与微信；README 更新入口及限制。

本轮单元测试覆盖微信/短信开关独立性、精确包名、分组摘要、微信正文/隐藏消息/金融噪声和规则页生产格式一致性。实际微信通知需真机收到通知后单独核验。
