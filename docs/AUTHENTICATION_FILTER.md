# 验证码误识别修复

腾讯等非金融平台的登录验证消息此前没有被金融关键词过滤覆盖，6～8位数字可能被长数字规则召回。

AuthenticationCodeFilter 统一处理验证码、校验码、动态密码、一次性口令及常见英文标签。纯验证消息在候选生成和学习之前退出；混合消息依据码值附近的标签归属过滤，保留明确取件码/凭码。最终入库再次判断，覆盖 AI 和其他自动识别入口。纯验证消息不会进入后台 AI 补充。

用户示例以同形态脱敏文本回归：腾讯登录验证、6位验证码、账号掩码和账号被盗提示均保留结构，不保存用户真实账号或验证码。另覆盖 OCR 跨行、全角数字、快递平台登录验证、验证码在数字之后，以及验证码和真实取件通知拼接/同行的情况。

过滤不自动删除既有记录；手动录入只有码值，缺少原消息上下文，仍由用户决定。

规则页面只保留可管理的规则及操作提示，不显示上下文与校验技术说明。
