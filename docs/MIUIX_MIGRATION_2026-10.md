# miuix 界面迁移

## 来源与版本

框架源码来自 [compose-miuix-ui/miuix](https://github.com/compose-miuix-ui/miuix)，采用 Apache-2.0 许可。固定使用 `v0.3.0`（`cca0d85`）及 Maven Central 的 `top.yukonga.miuix.kmp:miuix:0.3.0`，与项目 Kotlin 2.0.21、Compose 1.7、Android 35 环境匹配。完整许可和来源说明随 APK 放在 assets/licenses；源码下载到开发工作目录供接口核对，不把整个上游仓库或编译产物提交到应用仓库。

## 界面范围

- 首页、详情、通知来源、设置、身份码、地址、规则、统计、重复记录和回收站使用同一套 miuix 色彩、字体与平滑圆角。
- 标题栏、卡片、按钮、输入框、开关、复选框、滑条、图标和文字通过公共适配层使用 miuix 组件；标签、进度条、菜单和确认弹窗按同一风格补齐。
- 侧边栏继续支持手势与返回键，条目使用 miuix 样式；底部三个身份码入口和添加、分享的操作位置保留。
- Material3 的色彩角色、Snackbar 状态及抽屉手势容器仍作为兼容基础，界面控件不再逐页直接使用 Material3 的默认外观。操作回调、数据存储、系统授权与识别逻辑保持原有路径。
- 跟随系统、浅色、深色三种选择保留。输入提示移到字段下方，避免与 miuix 浮动标签重叠；滑条保留拖动结束保存和无障碍调整回调。

## 验证

321 项 JVM 单测通过，失败/错误均为 0；47/47 识别语料通过。新增菜单位置用例覆盖正常展开、底部向上展开、RTL 与窄窗口边界。最终界面代码的 Lint 无错误，正式签名 arm64 Release 使用 R8 与资源收缩，已构建成功。迁移仅修改界面与依赖，不修改记录数据库和识别规则。

miuix 包已在用户设备覆盖安装。进一步统一深浅色配对、普通卡片表面、状态标签和输入提示，修复底部三个身份码入口的文字/图标颜色；取消部分摘要和回收站正文额外的透明度。色彩对比度测试覆盖深浅色正文、摘要、输入提示、柔和强调及错误状态，相关组合均达到 4.5:1。详见 [主题统一与深浅色适配](MIUIX_THEME_2026-10.md)。

通知实际连接在用户调整 Thanox 权限并重启后恢复，本地合成通知验证结果见 [通知连接恢复](NOTIFICATION_CONNECTION_2026-10.md)。真实微信/购物平台通知与全部复杂数据、极端字体/分屏组合尚未逐项验证，随 v1.3.0 发行；上述未验证范围仍保留。
