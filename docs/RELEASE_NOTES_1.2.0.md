# 码上闪记 v1.2.0

本版改善取件码识别、记录管理和高频操作，仅提供 arm64-v8a APK。

- 增加普通短信及可选短信/微信通知识别，网络短信可通过默认短信应用通知识别；通知开关独立、默认关闭，需要通知访问授权和可见正文。
- 补齐三段取件码、六位柜码、八位柜机码等规则；规则管理同步显示可管理格式。修复 QQ 登录验证码被误收录等问题，技术校验说明保留在开发文档中。
- 主页默认全部记录，保留已取、过期筛选、已取恢复和批量已取；删除才进回收站。移除独立待取清单与备份/恢复功能。
- 淘宝码、菜鸟码、拼多多码固定在紧凑底栏，用竖线分隔。点击码值直接复制，已取/恢复带文字，删除收进菜单。
- 统一主题与圆角，适配深浅色、窄屏和大字体；列表排序/分组与设置解密移至后台，页面离开前台后停止订阅和计时。
- R8、资源收缩及原生库压缩，保留离线中文 OCR 和条码模型；只发布64位包。

## 验证与性能

293项单测及47/47识别语料通过，SQLite 6/7/8→9迁移检查通过。Debug/Release与Lint检查通过。真机验证包含数据保留升级、离线OCR/QR、已取恢复、复制、删除菜单、键盘、深浅色、窄屏/大字体布局。

同机ABBA对照（144条合成记录，每版10次进程冷启动、6轮滚动）：首帧中位数111→113ms，滚动P95均16ms、P99均18ms，legacy jank约0.93%→0.94%。两版表现相近，未宣称明显提速。[完整方法和限制](https://github.com/chenran0408/pickup-code-app/blob/v1.2.0/docs/performance/CONTROLLED_1.2.0.md)，结构化结果作为附件。

真实微信新通知、最终短信接收回归及低版本设备仍需继续验证；单测和合成数据不代替这些设备场景。

## 安装与签名

下载 `app-arm64-v8a-release.apk`；校验值见 `SHA256SUMS.txt`。这是 fork 的第一版独立正式签名，后续版本沿用相同密钥。标准 Android 设备无法直接覆盖使用上游密钥或调试密钥的安装包；请勿通过卸载旧版绕过签名校验，以免丢失本机记录。当前调试授权手机的签名兼容情况单独验证。
