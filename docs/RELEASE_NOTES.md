# 码上闪记 v1.3.0

本版统一 MIUIX 界面，改善大字操作和通知识别，并补齐图片识别反馈与分享导入体验。

- 首页、详情、各级设置、侧边栏与弹窗统一 MIUIX 风格；分别适配深浅色，修复底部淘宝码、菜鸟码、拼多多码入口不清晰的问题。
- “主题与显示”提供跟随系统、浅色、深色，以及大字模式。文字至少放大到 130%，尊重系统更大字号；侧边栏可滚动，常用按钮点击区域增大。
- 修复大字模式下通知识别页和规则页的拥挤布局：按钮与标签可换行，说明和应用列表统一滚动，键盘弹出后仍可搜索和勾选应用。
- 通知来源可按应用名称或包名搜索并选择，支持查看已选应用及系统应用。仅识别已选应用的新通知，不读取历史聊天或站内消息。
- 显示通知服务实际连接状态；授权返回、来源变化和断连时尝试恢复，并提供重新连接入口。系统自启动与后台限制仍可能影响通知识别。
- 图片分享显示识别进度与本次结果；未取、已取、过期状态更清晰。支持分享当前未取码，并从“添加码”粘贴分享文本或导入剪贴板，预览后确认保存。
- 保留离线中文 OCR、条码模型、验证码排除及本机数据存储；仅提供 arm64-v8a，继续启用 R8 和资源收缩。

## 验证

321 项 JVM 单测、47/47 识别语料及 SQLite 迁移检查通过；Lint 无错误，正式签名 Release 构建通过。已在设备检查深浅色、跟随系统、大字模式、侧边栏、底部入口、通知搜索/勾选/键盘滚动及代表性弹窗。合成通知验证取件入库、验证码排除与未选来源过滤。

通知实际连接在用户调整 Thanox 权限并重启后恢复，具体系统根因未单独隔离。真实短信、微信及购物平台推送尚未逐一验证；低版本设备、极端字号与分屏组合也未穷尽。本版没有新的性能对照数据，不宣称量化提速。

## 安装

支持 Android 8.0 及以上的 arm64 手机，下载 `app-arm64-v8a-release.apk`，校验值见 `SHA256SUMS.txt`。沿用 v1.2.0 的 fork 独立正式签名，可覆盖升级同签名版本，保留已有记录与设置。不同签名的上游版或调试版不能直接覆盖；不要为绕过校验卸载旧应用，以免丢失本机记录。
