# 码上闪记 v1.3.2

本版提供通用版和 MI-root 专用版两个安装包，按设备选择即可。

- **通用版**适用于 Android 8 及以上 arm64 手机，保留离线中文 OCR 与二维码识别模型，可覆盖升级旧版并保留原有数据。
- **MI-root 专用版**约 1.8 MiB，仅面向 Android 16/17 的 arm64 小米设备，直接使用系统 AICR 识别服务，不包含本地模型或备用识别引擎。若设备系统没有可用的 AICR 服务，图片 OCR 和二维码识别将不可用。
- 两个版本可以同时安装，但记录和设置相互独立。

请从本页附件下载对应 APK。下载后可使用 `SHA256SUMS.txt` 校验文件。
