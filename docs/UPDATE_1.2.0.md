# 1.2.0 更新与验证

版本：1.2.0 / 28；数据库：9。仅交付 arm64-v8a。

## 用户可见变化

- 主页默认显示全部记录，移除独立待取清单卡片和待取筛选；保留类型、已取、过期、时间/地址分组。
- 已取历史独立保留，可从主页或详情恢复。删除才进入回收站，24 小时后清理；旧版归档记录维持原行为，不猜测是否已取。
- 地点分组的批量已取只操作当前可见活跃记录，撤销只恢复原批次，不能恢复后来删除的记录。
- 地址全半角、空白、尾部句读差异可以合并；已知不同柜号不会仅凭同地址同码合并，运单相同仍作为同单证据。
- 短信/微信通知开关显示监听连接状态与最近事件的正文可读性，断开时可重新连接。普通聊天中的数字不生成取件码。
- 设置增加识别反馈：粘贴消息，随机替换数字并保持位数/分隔符，编辑姓名地址及预期结果，人工确认后保存文件；不自动发送。
- 按实际取件场景移除备份/恢复功能及实现，保留数据升级迁移。
- 保留此前的验证码排除、三平台大入口、可管理规则与本地先识别再 AI 补充。
- 合并 fork 已有的学习样本/常用站点加密、提醒请求码隔离及旧提醒取消修复，并适配按记录操作。

## UI 与操作优化

- 首页将淘宝码、菜鸟码和拼多多码放在固定底栏。底栏默认约 64dp（不含系统导航栏），三个入口等宽，使用细竖线分隔；大字体允许内容撑高，点击范围至少 48dp。
- 类型筛选保持一行，窄屏可横向滑动；状态/分组收成一行菜单；回收站、统计、去重收进顶部更多菜单。使用引导移至记录后方。
- 点击码值直接复制，点击卡片查看详情；已取/恢复使用有文字的按钮，删除放进记录菜单。窄屏或大字体将已取按钮移至卡片下方，优先展示码值。
- 主题统一灰蓝色表面、主色按钮、描边和圆角。设置页不再使用独立雾蓝强调色；弹窗、菜单及回收站卡片跟随公共主题，保留品牌图标和类型色。
- 手动添加自动聚焦码值并打开键盘，内容可滚动。

## 性能与安装包

Release 使用 R8 混淆/裁剪和资源收缩，保留离线中文 OCR / 条码模型；只生成 arm64 包。
首页记录排序、筛选和分组在 Default 后台线程生成，只计算当前分组方式；列表复用稳定 ID 和内容类型，卡片缓存日期格式及品牌映射。首页离开前台时停止 UI 数据订阅和每分钟刷新；重复统计取消旧任务。主题仅订阅主题项，完整设置中的密钥解密移至 IO 线程。
新增原生库 ZIP 压缩，安装时由系统解压。固定正则复用编译结果，减少地址分组、通知过滤及验证码归属判断中的重复编译。

在相同源码、同版本、未签名 Release 条件下，仅切换原生库压缩选项：

| arm64 发布包 | 字节 | MiB |
|---|---:|---:|
| 未压缩原生库 | 21,576,213 | 20.58 |
| 压缩原生库 | 12,046,545 | 11.49 |

下载体积减少 44.17%。最终功能精简后包略小，最终签名测试包大小以交付文件为准。
原生库解压后的安装占用不会同比减少。本轮未做稳定的帧率、内存峰值或冷启动对照测试，不将包体减少当成运行速度提升。
复现命令见 [BUILDING.md](BUILDING.md)。混淆映射保存在本地构建目录 `app/build/outputs/mapping/release/`。

## 验证

- JUnit：293 项，失败/错误/跳过均 0；识别语料 47/47，全屏地址断言 5/5。
- 实际 SQLite：6→9、7→9、8→9 数据与 schema 保留，旧地址回填拒绝；已取历史不随回收站清理，删除后的记录不会被旧批次撤销复活。
- Debug / Release 构建成功；最终 Lint Debug 0 错误，29 条警告（依赖版本、未用资源等）。
- Android 17 arm64 真机：R8 + 原生库压缩测试包保留数据覆盖安装；合成图片经相册正常分享，离线 OCR 取件码和 QR 券码入库，已取/恢复操作通过；测试记录清理后原有 6 条回收站记录仍保留。
- 本轮 UI 真机检查：浅/深色主题，点击码值复制、已取及恢复、详情、记录删除菜单、手动录入自动打开键盘均通过。1080×2400 临时分辨率 + 1.3 倍字体下，常见取件码完整显示，底栏标签保持单行；检查后恢复原分辨率、1.0 字体与跟随系统主题。只清理本轮合成记录，原有 6 条回收站记录保留。
- 新增列表投影测试覆盖已取/过期边界、券码筛选、时间边界及 10,000 条记录不丢失/不重复；这是正确性回归，不作为手机帧率基准。
- 真实微信通知仍需另一账号发送新消息验证；普通短信与网络短信的最终接收回归、标准签名环境升级、低版本设备尚未完成本轮真机验证。
